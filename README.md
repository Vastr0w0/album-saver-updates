# 图集拾光

一款用于保存抖音、小红书图集的轻量 Android 小工具。本仓库用于发布安装包、更新说明和接收问题反馈。

**0.3.1 修复 VPN 下保存停在 0/N 等待的问题。** 直接覆盖升级并打开应用即可继续旧队列，也可在“任务与历史”点“继续等待中的任务”。无需重新添加已经排队的链接。

## 下载与安装

在 [最新版本](https://github.com/Vastr0w0/album-saver-updates/releases/latest) 页面下载 `album-saver-v版本号.apk`，按 Android 系统提示安装。Android 10 及以上可用。

已有旧版本时直接覆盖安装，保留应用设置和已保存的照片。后续版本也可以在应用右上角“更新”中检查。

## 使用

1. 复制抖音或小红书图集的分享链接，整段分享文字也可以。
2. 在应用中点“粘贴并解析”，或在平台的系统分享菜单中选择“图集拾光”。
3. 选择要保存的图片，点“保存到相册”。
4. 点底部“新链接”，继续处理下一条。

图片保存在系统相册的“图集拾光”文件夹。

## 批量、历史和预览

- 多条链接可混合粘贴，点“链接加入队列 · 自动保存”，一次最多 30 条；会保存全部图片及已启用的动态片段。
- “任务与历史”中可查看进度、错误原因、原帖和图集，暂停或继续任务，只重试失败文件。
- 可以切到后台保存。首次建议允许进度通知；任务受到系统中断后会保留记录，再次打开应用可继续。
- 保存时允许使用应用当前可用的 VPN 网络。保持应用在前台时，系统调度未及时启动会尝试备用保存；无法启动时显示原因，不会只留下无解释的等待状态。
- 点缩略图打开大图，支持双指缩放、双击放大、拖动、左右翻图。“壁纸预览”按当前手机屏幕比例显示，不修改下载文件。
- “保存设置”中可开关动态片段，或选择保留完全相同的副本。默认跳过内容完全相同的文件；相似图只提示，仍由用户选择。

## 动态照片

识别网页提供的图集动态片段，可以在大图中播放，并与静态图片分别保存。图片在 `Pictures/图集拾光`，视频在 `Movies/图集拾光`。已有 GIF/WebP 下载文件保持原格式。

这是“图片＋独立视频”的保存方式，不承诺小米相册自动识别为原生实况照片。如果网页标记为动态照片但未提供动态地址，会保留静态图并给出可重试提示。

## 图片质量

- 优先选择平台可取得的较高清图片地址，保留下载文件的字节、格式和尺寸。
- 不将图片重新压缩，不用 AI 放大冒充原图。
- 优先选择不含平台水印的图片地址；原图片本身已有的签名、水印会保留。
- 平台提供的文件可能已经压缩过，无法保证等同于作者上传的原始文件。

## 更新

应用会核对新安装包的版本、SHA-256 和签名，再交给 Android 系统确认安装。首次更新可能需要在系统页面允许本应用安装更新包。

旧版本如果提示尚未设置更新地址，可以先在 Releases 下载新 APK 覆盖安装。
